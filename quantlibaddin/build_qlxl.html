Build QuantLibXL From Source Code
NB: These pages may be out of date. The project no longer provides source code tarballs / zip files. To compile the code, clone the repo and follow the README.md.
back to tutorials index

This document explains how to build QuantLibXL and its prerequisites from source code.

If you want a binary installation of the precompiled addin, go instead to the QuantLibXL web site.

For other tutorials which explain how to compile QuantLibAddin for platforms other than Microsoft Excel on Windows, return to the Tutorials index.

QuantLibXL can be built in either of two ways:

  • the hand-maintained Visual Studio solution files, which run on Windows and build the C++ libraries and the Excel XLL; and
  • the cmake build, which on Windows builds the same libraries and XLL. The cmake build is x64 only.

1 Choose a Build - Basic or Full

This tutorial offers a choice of two builds as summarized below. The choice applies to both the Visual Studio and the cmake build.

BuildDescription
Full This build performs autogeneration of QuantLibXL source code. Requires you to install Python; gensrc is included in the source archive. You can enhance/customize this build by editing addin XML metadata and re-running gensrc.
Basic For this build, the autogenerated source code has already been created for you, and is not recreated during the build. Does not require Python. To customize/enhance this build you would need manually to edit the autogenerated C++ source files.

2 Prerequisites

Before proceeding to compile the source code, consult the documents below.

2.1 Conventions

See the following document regarding naming conventions in use for the project: Conventions

2.2 Boost

QuantLibXL depends on Boost. You will need the compiled Boost libraries, the Boost header files alone are not sufficient. The build requires Boost 1.58 or later; this release was tested using Boost 1.83.

2.3 Python 3.x

For the Full build, some code is autogenerated by gensrc, which is a Python script. Before rebuilding QuantLibXL you need to have Python 3.x installed on your machine. Here is the link to the Python website: http://www.python.org/.

For the cmake build, gensrc is invoked automatically when you configure with -DRUN_GENSRC=ON (see 6 Build QuantLibXL with CMake), and cmake locates the Python interpreter for you.

For the Visual Studio Full build, if Python is installed on your machine so that .py files are associated with the Python executable, then the gensrc scripts should build OK with no modification required.

Otherwise, you might need to edit these files...

    ObjectHandler\gensrc\Makefile.vc
    QuantLibAddin\gensrc\Makefile.vc

...and set the PYTHON variable equal to the location of the Python executable on your machine, e.g:

    PYTHON=C:\Program Files\Python312\python.exe

3 A Note on Directories

You are now ready to proceed with the build. The source code is distributed as two downloads:

  • a single combined archive containing QuantLibXL together with its sibling projects gensrc, ObjectHandler and QuantLibAddin; and
  • QuantLib 1.42.0, the core C++ analytics library, which is released separately.

The build refers to the prerequisite projects QuantLib, ObjectHandler, QuantLibAddin, and (for the Full build) gensrc using relative pathnames. In order for this to work, these projects must reside side by side in the directory tree, and the name of each project's parent directory must not include the version number (e.g. QuantLib not QuantLib-1.42.0). The combined archive already contains gensrc, ObjectHandler, QuantLibAddin and QuantLibXL in the correct layout, so you only need to add QuantLib alongside them.

Create a new empty folder on your hard drive to serve as the root directory for the build. You can use any path; for purposes of this tutorial the build directory is C:\build_ql_1_42_0. Unpack the combined archive into that directory; it expands to a single top-level QuantLibAddin folder containing the bundled projects. Then unpack QuantLib alongside them and manually rename its target directory, removing the 1.42.0 suffix. After all of the source code is unpacked you should have the following directory structure: 

C:\build_ql_1_42_0\QuantLibAddin\gensrc (required only for the Full build)
C:\build_ql_1_42_0\QuantLibAddin\ObjectHandler
C:\build_ql_1_42_0\QuantLibAddin\QuantLib
C:\build_ql_1_42_0\QuantLibAddin\QuantLibAddin
C:\build_ql_1_42_0\QuantLibAddin\QuantLibXL

4 Install the Source Code

Download the combined source-code archive from:

<download-url>

and uncompress it to C:\build_ql_1_42_0. This single archive contains gensrc, ObjectHandler, QuantLibAddin and QuantLibXL, already laid out side by side under a top-level QuantLibAddin folder; no separate per-project download of those projects is required.

Then go to the QuantLib downloads page, download QuantLib-1.42.0.zip and uncompress it alongside the bundled projects, renaming the target directory to C:\build_ql_1_42_0\QuantLibAddin\QuantLib.

5 Build QuantLibXL with Visual Studio

The hand-maintained Visual Studio solutions select the platform toolset automatically from the version of Visual Studio used to open the solution (VS 2022 / v143 and VS 2026 / v145 are supported), so there is no longer a separate solution file per compiler version.

Basic build - open solution QuantLibXL\QuantLibXL_basic.sln.

Full build - open solution QuantLibXL\QuantLibXL_full.sln.

Choose configuration Release (static runtime) and platform x64 (Win32 is also supported), then do Build | Build Solution.

The build process creates the QuantLibXL XLL file QuantLibXL\xll\QuantLibXL-v145-x64-mt-s-1_42_0.xll (the exact name reflects your toolset and platform). Instructions for loading the addin are provided in the QuantLibXL installation document: http://www.quantlibxl.org/installation.html

6 Build QuantLibXL with CMake

The cmake build is x64 only. It builds each project into its own build tree, so you build the prerequisites first and then point the QuantLibXL build at them. To see the presets available on your platform, run cmake –list-presets; the example below uses the windows-vs2026-x64-static preset. The -DRUN_GENSRC=ON option selects the Full build (it runs gensrc to regenerate the autogenerated source code and requires Python 3); omit it for a Basic build.

Build QuantLib, ObjectHandler and QuantLibAddin first (see Build A QuantLibAddin C++ Environment on Windows and/or Linux for the addin libraries), then configure and build the XLL:

cd C:\build_ql_1_42_0\QuantLibAddin\QuantLibXL
cmake --preset windows-vs2026-x64-static -DRUN_GENSRC=ON ^
    "-DCMAKE_PREFIX_PATH=../QuantLib/build/windows-vs2026-x64-static;../ObjectHandler/build/windows-vs2026-x64-static;../QuantLibAddin/build/windows-vs2026-x64-static"
cmake --build build\windows-vs2026-x64-static --config Release --target QuantLibXL

The build produces the same QuantLibXL XLL described above. Instructions for loading the addin are provided in the QuantLibXL installation document: http://www.quantlibxl.org/installation.html
