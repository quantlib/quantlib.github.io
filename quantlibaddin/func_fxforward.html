long SettlementDays

Description:

Construct an object of class FxForward and return its id

Supported Platforms:

Excel, C++

Parameters
ObjectIdid of object to be created
SourceNominalNotional amount in source (domestic) currency.
SourceCurrencySource currency (e.g. USD).
TargetNominalNotional amount in target (foreign) currency.
TargetCurrencyTarget currency (e.g. EUR).
MaturityDateSettlement / maturity date of the forward contract.
PaySourceCurrencyTRUE to pay source currency and receive target currency; FALSE for the opposite.
SettlementDaysNumber of business days for payment settlement (0=O/N, 1=T/N, 2=Spot). Default value = 2.
PaymentCalendarCalendar used to advance the settlement date. Default value = NullCalendar.
Permanentobject permanent/nonpermanent
Triggerdependency tracking trigger
Overwriteoverwrite flag
