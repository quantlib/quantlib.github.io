Build A QuantLibAddin C++ Environment on Windows and/or Linux
NB: These pages may be out of date. The project no longer provides source code tarballs / zip files. To compile the code, clone the repo and follow the README.md.
back to tutorials index

Overview

This document provides general instructions for building a QuantLibAddin C++ environment. Two builds are supported:

  • the hand-maintained Visual Studio solution file, which runs on Windows; and
  • the cmake build, which runs on Windows and on POSIX systems such as Linux. On Windows the cmake build is x64 only.

The source code is distributed as a single archive that bundles QuantLibAddin together with gensrc and ObjectHandler. The core QuantLib library is released separately and must be downloaded alongside them.

1 Prerequisites

Before proceeding to compile the source code, consult the documents below.

1.1 Conventions

See the following document regarding naming conventions in use for the project: Conventions

1.2 Boost

QuantLibAddin depends on Boost. You will need the compiled Boost libraries, the Boost header files alone are not sufficient. The build requires Boost 1.58 or later; this release was tested using Boost 1.83.

1.3 Python 3.x

Some QuantLibAddin code is autogenerated by gensrc, which is a Python script; gensrc is included in the source archive. Before rebuilding QuantLibAddin you need to have Python 3.x installed on your machine. Here is the link to the Python website: http://www.python.org/.

For the cmake build, gensrc is invoked automatically when you configure with -DRUN_GENSRC=ON, and cmake locates the Python interpreter for you.

For the Visual Studio build on Windows, if Python is installed on your machine so that .py files are associated with the Python executable, then the gensrc scripts should build OK with no modification required.

Otherwise, you might need to edit these files...

    ObjectHandler\gensrc\Makefile.vc
    QuantLibAddin\gensrc\Makefile.vc

...and set the PYTHON variable equal to the location of the Python executable on your machine, e.g:

    PYTHON=C:\Program Files\Python312\python.exe

2 Visual Studio

2.1 Download

2.1.1 Directories

The Visual Studio project files for QuantLibAddin rely on relative pathnames to refer to the prerequisite projects QuantLib, gensrc, and ObjectHandler. In order for this to work, these projects must reside side by side in the directory tree, and the name of each project's parent directory must not include the version number (e.g. QuantLib not QuantLib-1.42.0). The combined archive already contains gensrc, ObjectHandler and QuantLibAddin in the correct layout, so you only need to add QuantLib alongside them.

Create a new empty folder on your hard drive to serve as the root directory for the build. You can use any path; for purposes of this tutorial the build directory is C:\build_ql_1_42_0. After unpacking (below) you should have the following directory structure: 

C:\build_ql_1_42_0\QuantLibAddin\gensrc
C:\build_ql_1_42_0\QuantLibAddin\ObjectHandler
C:\build_ql_1_42_0\QuantLibAddin\QuantLib
C:\build_ql_1_42_0\QuantLibAddin\QuantLibAddin

2.1.2 Uncompress the Source Code

Download the combined source-code archive from:

<download-url>

and uncompress it to C:\build_ql_1_42_0. This single archive contains gensrc, ObjectHandler and QuantLibAddin, already laid out side by side under a top-level QuantLibAddin folder; no separate per-project download of those projects is required.

Then go to the QuantLib downloads page, download QuantLib-1.42.0.zip and uncompress it alongside the bundled projects, renaming the target directory to C:\build_ql_1_42_0\QuantLibAddin\QuantLib.

2.2 Build

A single solution file, QuantLibAddin\QuantLibAddin.sln, is provided. The platform toolset is selected automatically from the version of Visual Studio used to open the solution (VS 2022 / v143 and VS 2026 / v145 are supported), so there is no longer a separate solution file per compiler version.

Open the solution, choose configuration Release (static runtime) and platform x64, and execute menu item Build | Build Solution.

2.3 Test

Open a DOS prompt in directory 

C:\build_ql_1_42_0\QuantLibAddin\QuantLibAddin\Clients\Cpp\bin

Execute the example program. The output should appear similar to the following: 

Begin example program.
QuantLibAddin version = 1.42.0
ObjectHandler version = 1.42.0
option PV = 3.84431
End example program.

2.4 Usage

2.4.1 #include

Add the following directive to your project's source file: 

#include <qlo/qladdin.hpp>

2.4.2 Link

Your project's link to the QuantLibAddin library is established automatically by the directive 

#pragma comment(lib, QLADDIN_LIB_NAME)

in file qlo/auto_link.hpp

The name of the library depends on your compiler and configuration. For example, if you're using VS 2026 (v145), platform x64, configuration Release (static runtime), the library is called 

QuantLibAddin\lib\QuantLibObjects-v145-x64-mt-s-1_42_0.lib

3 CMake

The cmake build runs on both Windows and POSIX systems (e.g. Linux); on Windows it is x64 only. It builds each project into its own build tree, so you build the prerequisites QuantLib and ObjectHandler first and then point the QuantLibAddin build at them. To see the presets available on your platform, run cmake –list-presets; only presets whose host condition matches your current operating system are listed.

3.1 Download

3.1.1 Directories

This example assumes that you do not have root access to your machine, so that the entire build environment resides under your home directory.

Let's say your home directory is /home/username. Create a directory where you will unpack and compile the code. For purposes of this tutorial it is: 

/home/username/build

3.1.2 Uncompress the Source Code

Download the combined source-code archive from:

<download-url>

and uncompress it under /home/username/build. This single archive contains gensrc, ObjectHandler and QuantLibAddin, already laid out side by side under a top-level QuantLibAddin folder. Then download QuantLib-1.42.0.tgz from the QuantLib downloads page and uncompress it alongside them, renaming the target directory to QuantLib. After unpacking you will have, among others: 

/home/username/build/QuantLibAddin/gensrc
/home/username/build/QuantLibAddin/ObjectHandler
/home/username/build/QuantLibAddin/QuantLib
/home/username/build/QuantLibAddin/QuantLibAddin

3.2 Build

The cmake build is driven by presets. The example below uses the Linux preset linux-gcc; on Windows you would select one of the windows-... presets instead (e.g. windows-vs2026-x64-static). The -DRUN_GENSRC=ON option runs gensrc (a Python 3 script) to regenerate the auto-generated source code; it is required for the first build from a fresh release.

Build the prerequisites QuantLib and ObjectHandler first, then configure and build the QuantLibAddin wrapper library and the C++ demo client (QLADemo), telling cmake where the prerequisite build trees are:

cd /home/username/build/QuantLibAddin/QuantLibAddin
cmake --preset linux-gcc -DRUN_GENSRC=ON \
    -DCMAKE_PREFIX_PATH="../QuantLib/build/linux-gcc;../ObjectHandler/build/linux-gcc"
cmake --build --preset linux-gcc --target QLADemo

Building QLADemo first builds its prerequisites, the QuantLibAddin wrapper library QuantLibObjects and the C++ addin library AddinCpp.

3.3 Test

The demo client is written to the preset's build tree under cpp/:

cd /home/username/build/QuantLibAddin/QuantLibAddin/build/linux-gcc/cpp
./QLADemo

This should generate output similar to the following:

Begin example program.
QuantLibAddin version = 1.42.0
ObjectHandler version = 1.42.0
option PV = 3.84431
End example program.

3.4 Usage

To incorporate QuantLibAddin functionality into your own applications:

Suppose your application consists of source file yourapp.cpp: 

#include <qlo/qladdin.hpp>
#include <iostream>

int main()
{
    std::cout << QuantLibAddin::qlAddinVersion() << std::endl;
}

To compile your program, ensure that the paths containing the QuantLibAddin, ObjectHandler and QuantLib headers are among those searched by your compiler, e.g:

g++ -I/home/username/build/QuantLibAddin/QuantLibAddin \
    -I/home/username/build/QuantLibAddin/ObjectHandler \
    -I/home/username/build/QuantLibAddin/QuantLib \
    -c -o yourapp.o yourapp.cpp

When linking your program use the -l option to tell gcc to link to the ObjectHandler, QuantLib, and QuantLibAddin libraries, and use -L to specify the paths containing those libraries, e.g:

g++ -o yourapp yourapp.o \
    -L/home/username/build/QuantLibAddin/QuantLibAddin/build/linux-gcc \
    -L/home/username/build/QuantLibAddin/ObjectHandler/build/linux-gcc \
    -L/home/username/build/QuantLibAddin/QuantLib/build/linux-gcc \
    -lQuantLibObjects -lObjectHandler -lQuantLib
